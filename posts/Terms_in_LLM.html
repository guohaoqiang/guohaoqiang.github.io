Terms Frequently Seen in LLM inference

Model

  • Prefill
  • Decode

System

  • Time-To-First-Token (TTFT): The latency between the request arrival and the first output token generated by the system for the request. It includes the scheduling delay and the prompt processing time.
  • Time-Per-Output-Token (TPOT): Average time taken to generate a token (Total Decode Time / Number of Tokens).
  • Time Between Tokens (TBT)
